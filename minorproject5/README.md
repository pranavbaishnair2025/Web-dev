# NovaCart E-commerce Frontend

NovaCart is a responsive e-commerce frontend built with React and React Router. It demonstrates state management with Context API, reusable components, product listing, product details, search/filtering, and a shopping cart with quantity controls.

## Features
- Home page with featured products and call-to-action sections
- Product listing page with search, category filtering, and sorting
- Product detail page with product description and add-to-cart action
- Shopping cart with quantity updates, removal, and total summary
- Persistent cart data using local storage

## Project Structure
- src/components - reusable UI components
- src/pages - route-based pages
- src/context - shopping cart and product state management
- src/index.css - complete styling for responsive layout

## Run Locally
1. Install dependencies:
   npm install
2. Start the development server:
   npm run dev
3. Open the local URL shown in the terminal.

## Build
npm run build
